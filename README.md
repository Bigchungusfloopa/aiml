# AI-Generated Text Detection System

Detects whether text is **human-written**, **raw AI-generated**, or **humanized
(paraphrased) AI**. Web app + classical-ML backend. Implements
[SRS_AI_Text_Detection.md](SRS_AI_Text_Detection.md).

## Architecture (SRS §6)

```
                 ┌───────────────── always-on evidence (FR-17) ─────────────────┐
input text ──┬──▶ rule-based style checker  (rules.py)      ─┐
             ├──▶ GPT-2 perplexity/burstiness (perplexity.py) ─┤
             │                                                 ├──▶ combined result
             └──▶ Stage 1: raw AI vs human  (model_raw.pkl) ───┤        (detector.py)
                        │ confident "AI"? ──▶ done (FR-18)      │
                        │ else "Human"  ──▶ Stage 2 (FR-19) ────┘
                          Stage 2: humanized AI vs human (model_humanized.pkl)
```

- **Trained components are classical only** — TF-IDF + Logistic Regression
  (SRS constraint §2.4). GPT-2 small is used *pre-trained*, for perplexity
  scoring only — never trained here.

## Layout

| Path | Role |
|---|---|
| `src/aitext/preprocess.py` | text normalization, sentence splitting (FR-2) |
| `src/aitext/datasets_build.py` | build Stage 1 / Stage 2 CSVs from MAGE or HC3 + mixed humanizer (FR-1) |
| `src/aitext/train.py` | word+char TF-IDF → Logistic Regression, CV-tuned `C`, persist (FR-3…FR-9) |
| `src/aitext/rules.py` | em-dash, cliché, sentence-uniformity checker (FR-10…FR-13) |
| `src/aitext/perplexity.py` | GPT-2 perplexity + burstiness, optional calibrator (FR-14…FR-16) |
| `src/aitext/calibrate_perplexity.py` | fit the perplexity→P(AI) logistic calibrator on real data |
| `src/aitext/detector.py` | cascade orchestration + confidence bands (FR-17…FR-25) |
| `src/aitext/evaluate.py` | held-out Stage 1 / Stage 2 / 3-way cascade metrics |
| `src/aitext/report.py` | confusion-matrix + perplexity figures, `docs/results.md` |
| `src/aitext/extract.py` | PDF / DOCX / TXT → plain text for the upload tab |
| `app.py` | Streamlit UI: paste **or upload**, result + evidence (FR-21…FR-25) |
| `config/cliches.txt` | maintained cliché list — edit without touching code (NFR-6) |
| `models/` | persisted `.pkl` artifacts (Appendix A) — `*.pkl` committed |
| `data/` | prepared + held-out CSVs — gitignored, regenerated by `datasets_build` |
| `REPORT.md`, `DEPLOY.md` | project writeup and deployment guide |

## Setup

```bash
# Use Python 3.10–3.12 (this project was built on 3.12).
python3 -m venv .venv
source .venv/bin/activate          # then `python` / `streamlit` resolve here
pip install -r requirements.txt
```

If `streamlit: command not found` or `No module named streamlit`, your shell's
`python3` isn't the one you installed into — activate the venv (above), or call
it explicitly: `.venv/bin/streamlit run app.py`.

## Train the models

```bash
# 1. Build datasets — MAGE (10 domains) for Stage 1, mixed humanizer for Stage 2.
#    Downloads MAGE + the T5 paraphraser on first run; GPU paraphrasing ~25 min.
PYTHONPATH=src python -m aitext.datasets_build --max-per-class 8000
#      --source hc3                 use HC3 (Q&A only) instead of MAGE
#      --humanizer t5|pseudo|mix    Stage 2 humanizer (default: mix)
#      --mix t5=0.5,pseudo=0.3,realpara=0.2
#      --humanized-csv data/mine.csv   your own Quillbot / Undetectable.ai output

# 2. Train + persist both stages (writes models/*.pkl and data/*_test.csv)
PYTHONPATH=src python -m aitext.train

# 3. Calibrate the GPT-2 perplexity signal on real data (optional, ~8 min GPU)
PYTHONPATH=src python -m aitext.calibrate_perplexity --sample 500

# 4. Evaluate + build report figures
PYTHONPATH=src python -m aitext.evaluate
PYTHONPATH=src python -m aitext.report
```

`datasets` ≥3 dropped script-based loaders, so MAGE/HC3 are pulled as raw
CSV/JSONL via `huggingface_hub`. GPU/MPS is used automatically for the T5
paraphraser and GPT-2 when available.

## Results

Trained on **MAGE + HC3**, 9,000 samples/class, stratified 80/20 split. Full
tables + confusion matrices: **[REPORT.md](REPORT.md)** /
[`docs/results.md`](docs/results.md) (`python -m aitext.report`).

| Held-out | Accuracy | ROC-AUC |
|---|---|---|
| Stage 1 — raw AI vs human | 82.0 % | 0.912 |
| Stage 2 — humanized AI vs human | 85.8 % | 0.941 |
| **Cascade — binary (AI vs human)** | **89.1 %** | — |
| Cascade — 3-way (human / raw-ai / humanized-ai) | 61.5 % | — |

Humanized AI is still flagged as AI-generated **96.6 %** of the time — the
cascade only struggles to tell *raw* from *humanized* AI (both are AI text).
Human false-positive rate ≈ 16 % (the cost of MAGE's hard, varied human writing;
HC3-only scores ~96 % but doesn't generalise).

## Run the app

```bash
streamlit run app.py
```

Paste text **or upload a PDF / Word / text file**; the result panel shows the
label, a confidence band, and an expandable evidence breakdown (Stage 1/2
scores, cliché flags, perplexity/burstiness).

The app degrades gracefully (NFR-3) if models are missing — it shows the
rule-based + perplexity evidence and tells you to train.

The trained `models/*.pkl` are committed, so a fresh clone runs the app without
retraining.

## Deployment (NFR-7)

See **[DEPLOY.md](DEPLOY.md)**. Short version: Hugging Face Spaces (full app with
GPT-2) or Streamlit Community Cloud (use `requirements-lite.txt` if the free
tier's ~1 GB RAM can't hold torch). `models/*.pkl` are committed, so no training
step on the host.

## Known limitations (SRS §9)

- Well-humanized AI text frequently evades detection — industry-wide.
- False positives on unusually formal/simple text and non-native English.
- English only. No cryptographic watermark verification.

## Troubleshooting

- `AttributeError: module 'hashlib' has no attribute 'blake2b'` (Streamlit won't
  start) — your Python's `_blake2` extension can't find `libb2`. Fix on macOS
  with `brew install libb2`.
- `RuntimeError: Dataset scripts are no longer supported` — you're on an old
  `datasets`; this repo already works around it by pulling HC3 as raw JSONL.
